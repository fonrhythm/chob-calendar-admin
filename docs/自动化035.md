# 自动化 035

复用现有网站、Admin 和 Supabase 034。没有部署、执行生产 SQL、启用付费 API 或启动后台监控。

## 启用

1. 先在测试库核对已有迁移到 034，再执行 `supabase/035_automation.sql`。035 只新增表与接口，保留现有数据。不要重跑旧初始化/清理迁移。
2. Admin 活动表单的「来源、变更与实体关系 → 自动化来源与扫描记录」添加来源，保留角色备注，输入首次扫描开始时间，人工核验身份并启用。
3. 提供实际采集与提取模块；没有配置的 provider 明确报错，不生成虚假帖子。模块导出 `transports`（平台到 async 函数）及 `extract`。X 优先；Grok 可作为传输实现，但此版本没有调用或购买服务。
4. 环境变量：`CHOB_PROVIDER_MODULE`、`CHOB_SUPABASE_URL`、`CHOB_SUPABASE_KEY`（public key）、`CHOB_EDITOR_TOKEN`（现有获批 Web 编辑者 JWT）。凭证仅从运行环境读取，不放入源码。JWT 过期需刷新。
5. 在 Web 仓库运行 `npm run test:automation`，随后 `npm run automation:scan` 预览。预览保存原始证据，不改活动、不提交审核、不推进游标。核对后运行 `npm run automation:scan -- --apply`。持续扫描用 `--apply --watch`；`CHOB_SCAN_INTERVAL_MS` 可配置，默认 60000 是可修改技术默认值，不是业务实时 SLA。

## Provider 契约

`transports.x({account,cursor,since,keywords,signal})` 返回 `{posts,cursor,complete}`。每条真实帖子包含 `id,account,url,published_at,text,media?`；account 必须与配置账号完全相同。cursor 是可序列化 JSON，失败不得推进。complete 表示本次增量扫描结束。传输模块负责平台授权、限流和分页，只返回真实取得的内容。缺配置时报错。图片引用作为证据保存；OCR 不能把看脸识人当作事实。

`extract({raw,dictionaries,instruction,signal})` 返回 `{facts,translations:{zh,en,th}}`。字段为 `{state:'known'|'tba'|'missing',value?,quote?}`；known 值及 TBA 声明必须可在原文引句中验证。当前严格校验仅自动接受可直接核对的 ISO 日期/24 小时时间；其他语言日期、归一化和 OCR 结果进入人工审核，不能伪造原文来通过校验。

支持字段：title/date/time/location/city/region/artist_names/category/participation_condition/ticket_url/link_kind/picture_url/note/sale_date/sale_time/sale_end_date/sale_end_time/roll_call/event_status/scope/content_kind/venue_name/parent_identity/previous_source_url/change_kind。

scope 需明确公开活动/直播证据（`public event`、`公开活动`、`公开直播`、`online live`、`public livestream`）；排练、拍摄、私人等排除。节目/音乐 `content_kind=episode/trailer/mv/song/album/broadcast` 存独立内容表。不能根据关键词把 final ep 当成公开活动。分类和参与方式精确匹配现有字典名称、code 或 aliases；未知参与方式不默认无限制。region 为 china/thailand/oversea 或明确中文对应值。

同标题、日期、场地、已公布艺人集合一致时链接同活动；其他疑似重复送审。明确变更通过原文 `previous_source_url` 指向已关联来源并有 `change_kind=changed/cancelled/postponed/additional artists/变更/取消/延期/追加艺人` 时可更新，否则官方冲突送审。取消/延期复用现有 event_status。不确定的父子关系、roll_call、未知艺人和场地交由现有表单确认。

## 审核与维护

活动表单显示原始来源、原文、中文翻译和提取结果。填写审核结论，选择「编辑后批准」或「合并来源到当前活动」，在原有表单完成字段、艺人及事项后保存。关联旧活动的审核需打开该活动；草稿可保存，发布沿用现有校验。批准、活动保存、历史及旧活动通知在同一事务内；保存失败不消耗审核。拒绝沿用已有审核接口。新增艺人/别名/场地仍在现有后台人工操作。

扫描记录包含账号、开始/结束、游标、各类计数和失败原因。失败页面重试时已完成的帖子通过 post ID + 内容 hash 跳过；游标只在页面全部成功持久化后推进。租约避免并行扫描，同条来源提交由数据库锁和唯一处理记录防重。停用账号后不会继续提交新活动。超时租约下次扫描记录失败并恢复。

`table-export.mjs` 提供旧 17 列 TSV 导出，沿用现有表格导入；保留完整艺人关联，CP 仅显示本次两位都参与的组合。最早主图不被提醒图覆盖，所有媒体仍在来源快照中；需要更换主图的关键变更可在审核表单确认。

生产前还需真实 provider、测试库及用户凭证验证。fixture 的成功不代表平台采集可用；测试不写生产数据。出现异常先停用来源，检查 scan error 与审核队列；不要删除原始来源、处理记录或历史。
